HomeMediaViewer

v0.3-web

局域网内多台设备互相发现、浏览、点播彼此的音视频文件，无需拷贝源文件。

功能特性

  • mDNS 设备自动发现
  • HTTP + Range 流媒体服务
  • 跨设备播放与投屏
  • 媒体分组浏览
  • 播放队列管理
  • 播放速度调节
  • 深色模式

技术栈

  • HTML5 / CSS3 / Vanilla JS
  • HTML5 Video / Audio API
  • CSS Grid / Flexbox
  • localStorage 持久化
